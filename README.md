# Сокровища чёрного кота

Слот-симулятор 5×3 с 20 линиями. Одна кодовая база на две площадки:
RuStore (Capacitor/APK) и ВК Игры (iframe/VK Bridge).

## Быстрый старт

```
npm install
npm run dev
```

Открыть http://localhost:5173

## Сборка

| Команда | Что делает |
|---|---|
| `npm run build` | сборка в `dist/` — для RuStore |
| `npm run build:vk` | сборка в `dist-vk/` — для ВК Игр |
| `npm run sync` | сборка + `cap sync android` |

## Математика

Проверена на 2 млн спинов:

- RTP — 93,95%
- выигрыш примерно на каждом третьем спине
- 41,5% всех выплат приходит из бесплатных спинов
- бонус — раз на ~138 спинов
- максимальный занос — ×982 от ставки

Правится в `src/game/core.ts`: таблица выплат в `SYMBOLS`, частоты
символов в `BASE_REELS` и `FREE_REELS`. После любой правки лент RTP
надо перемерить — иначе игра станет либо жадной, либо слишком щедрой.

## Структура

```
src/
  game/core.ts        математика: символы, линии, ленты, оценка выигрыша
  store/gameStore.ts  состояние и игровой цикл (Zustand)
  audio/audio.ts      весь звук синтезируется, аудиофайлов нет
  platform/index.ts   адаптер: реклама и сохранение для RuStore / ВК
  components/         экраны и элементы интерфейса
public/
  symbols/            15 символов, 256×256, с прозрачностью
  bg.jpg              двор днём — основная игра
  bg_night.jpg        двор ночью — бесплатные спины
```

## Что нужно настроить перед публикацией

1. **Слоты рекламы** — `AD_SLOTS` в `src/platform/index.ts`, значения из кабинета VK Ads.
2. **Иконки Android** — скопировать `android-icons/*` в `android/app/src/main/res/`.
3. **Возрастной рейтинг 18+** в карточках RuStore и ВК Игр.
4. **Дисклеймер** про отсутствие реальных денег — уже в игре, продублировать в описании.

Подробности по Android — в `android-setup.md`.
