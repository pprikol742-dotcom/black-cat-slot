# Публикация во ВКонтакте

Хостинг у ВК свой, бесплатный, с CDN. Свой домен и сертификат не нужны —
публикация идёт одной командой из PowerShell.

Все команды выполняются в папке проекта:

```powershell
cd C:\black-cat-slot
```

---

## Шаг 1. Создать приложение

Открой https://dev.vk.com → «Мои приложения» → «Создать приложение».

| Поле | Значение |
|---|---|
| Название | Сокровища чёрного кота |
| Платформа | VK Mini App |
| Тип | Игра |
| Возрастное ограничение | **18+** |

После создания в настройках будет номер приложения — это `app_id`.
Запиши его, он нужен дальше.

## Шаг 2. Прописать номер приложения

Подставь свой номер вместо `12345678`:

```powershell
(Get-Content vk-hosting-config.json -Raw) -replace '"app_id": 0', '"app_id": 12345678' | Set-Content vk-hosting-config.json
```

Проверить:

```powershell
Get-Content vk-hosting-config.json
```

## Шаг 3. Установить зависимости

```powershell
npm install
```

## Шаг 4. Опубликовать

```powershell
npm run deploy
```

При первом запуске откроется вход через ВКонтакте — надо разрешить доступ.
Дальше команда сама соберёт VK-версию, упакует и зальёт на хостинг.
Спросит, публиковать ли в production — отвечай `y`.

Готово. Игра доступна по адресу `vk.com/app12345678` со своим номером.

> Деплой разрешён не больше 24 раз в сутки.

## Шаг 5. Оформить карточку

В настройках приложения загрузи из папки `store-assets`:

- `icon_vk_256.png` — иконка
- `banner.jpg` — обложка 1200×630

Описание — обязательно с оговоркой:

> Слот-симулятор про чёрного кота и его сокровища. 5 барабанов, 20 линий,
> бесплатные спины с липкими вайлдами. Игровые монеты не имеют реальной
> ценности, вывод и обмен на деньги невозможны. Игра на реальные деньги
> отсутствует. 18+

## Шаг 6. Модерация

Отправь приложение на проверку в настройках.

Доделай всё до отправки: пока идёт модерация, вносить правки нельзя.

На что смотрят у игр этого жанра:

- возрастное ограничение 18+ выставлено;
- в описании и внутри игры сказано, что монет за деньги не купить;
- нет ссылок наружу на настоящие казино и ставки;
- игра работает и в мобильном ВК, и в браузере.

---

## Что меняется во ВК само

Ничего настраивать не надо, адаптер разбирается по ходу:

| | RuStore | ВКонтакте |
|---|---|---|
| Реклама | VK Ad SDK, нативный плагин | `VKWebAppShowNativeAds` |
| Прогресс | память устройства | облако ВК, переносится между устройствами |
| Экран | портрет телефона | iframe, чаще широкий |

Мост ВК подключается только в VK-сборке. В APK для RuStore он подменяется
заглушкой и места не занимает.

## Проверка перед отправкой

```powershell
npm run build:vk
```

```powershell
npx vite preview --outDir dist-vk
```

Учти: вне ВКонтакте мост не отвечает, поэтому прогресс уйдёт в память
браузера, а реклама не покажется. Внутри ВК всё заработает.

## Если понадобится сбросить вход

```powershell
Remove-Item "$env:USERPROFILE\.config\configstore\@vkontakte\vk-miniapps-deploy.json" -Force
```

## Важно про сборку для RuStore

`npm run deploy` пересобирает папку `dist` в VK-версии. Перед сборкой APK
обязательно пересобери обычную версию:

```powershell
npm run sync
```

Эта команда сама делает `npm run build` и переносит свежую сборку в проект
Android.
